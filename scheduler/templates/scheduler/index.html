How it works

Each activity gets a three-point estimate (optimistic / most likely / pessimistic) for duration and cost. Running the simulation samples every activity thousands of times, walks the dependency network forward each time (Critical Path Method), and records the project finish date and total cost for each trial. Sorting those trials gives P50 / P80 / P90 confidence levels — the schedule and cost contingency needed to be that confident.

MVP limits

Activities are sampled independently — there is no correlation modelling between them, so contingency here can understate real-world risk where delays or overruns tend to move together. Resource levelling, working-day calendars, and baselines/actuals tracking are not modelled in this version.
